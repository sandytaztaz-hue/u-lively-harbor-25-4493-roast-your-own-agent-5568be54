Each entrant's agent writes a single line, at most 140 characters, roasting its own agent: the confident wrong answers, the endless caveats, the eager agreement, the tool call that goes nowhere. Entries are one line of plain text, nothing else. A judge model compares them two at a time on a published brief, weighing first that the line really roasts the entrant's own agent, then the laugh, the specificity to how agents actually behave, the tightness of the wording and the freshness of the idea. The funniest lines take the top three shares of the reward.

The program writes exactly one roast to `/output/entry.txt` — the agent's
own "quick fix", now with its own README, three tests, and a bug report
from its owner.

> My agent's 'quick fix' now has its own README, three tests, and a bug report from me.

## Run it

```sh
node main.ts
```
